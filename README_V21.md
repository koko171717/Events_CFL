# CFL Control V21 — Grille annuelle par défaut

Correctif ciblé depuis la V20.

- Au chargement de l’Agenda Admin, après authentification Supabase, la vue initiale est **Grille annuelle** (et non Synthèse annuelle).
- Les raccourcis vers les années des brouillons ouvrent également la **Grille annuelle**.
- Les vues Synthèse annuelle et Vue mensuelle restent disponibles manuellement.
- Aucune modification de SQL, des données Supabase, de CFL TV ou de l’agenda public.

Déployer les fichiers du ZIP à la racine du dépôt GitHub existant.
