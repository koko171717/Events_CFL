# CFL CONTROL V46 — Box fermée

1. Dans **Supabase SQL Editor**, exécuter `supabase/06_box_fermee.sql` une seule fois **avant** d'utiliser la nouvelle case.
2. Déployer le contenu de ce dossier à la racine du projet GitHub/Vercel.
3. Ouvrir l'Agenda admin, modifier un événement et cocher **Box fermée pendant cet événement**. Enregistrer.
4. Dans l'Agenda public, la mention **BOX FERMÉE** apparaît dans la fiche détail de cet événement.
5. Dans CFL TV, la slide de l'événement et la slide « Événements du mois » affichent la mention si l'événement est fermé.
6. Après modification d'un événement, **republier la playlist CFL TV** afin de mettre à jour les écrans publiés. Les slides de type événement peuvent utiliser des snapshots lors de la publication.

La case est décochée par défaut. Elle est indépendante du type de l'événement et ne ferme pas automatiquement les réservations ou les cours.

Base : V45. Les adaptations des WOD, des consignes athlètes, de l'agenda et du design sont conservées.
