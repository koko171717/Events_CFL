# V40 — Athlete Instructions (Studio WOD)

- Source Webwidget historique : les consignes ne sont pas systématiquement exposées.
- Import manuel autorisé de la réponse JSON `wod_board` depuis votre navigateur BTWB connecté. Seul le titre et le corps des notes de `track_event_instructions` pour le track sélectionné sont conservés, en `localStorage`, datés par jour Europe/Zurich. Les données personnelles et la réponse JSON complète ne sont pas stockées par le Studio.
- Possibilité de corriger/enregistrer et effacer les consignes manuellement.
- Attention : stockage local au navigateur ; **pas de synchronisation automatique vers les TV**. Les Webwidgets BTWB et la playlist en production restent inchangés.
- Pour une diffusion automatique partagée, une intégration officiellement autorisée à BTWB et un stockage partagé seront nécessaires.
