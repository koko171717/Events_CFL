# CFL CONTROL V44 — WOD personnalisé dans la playlist

Le nouveau module « WOD CFL personnalisé » est disponible dans le type de slide BTWB. Il utilise le cadre graphique, le logo et les couleurs de CFL TV déjà utilisés par les autres slides, et extrait le HTML du Webwidget officiel.

La version BTWB historique reste inchangée et disponible comme solution de secours. Le contenu se renouvelle lorsque la slide est rechargée, notamment lors des rotations de la playlist. Plusieurs blocs sont affichés au besoin par rotation interne.

Aucune modification SQL. Pour activer : CFL TV > ajouter une slide > BTWB > WOD CFL personnalisé > sélectionner la programmation > Enregistrer > Publier. Prévisualiser avant publication.

Limites : l'extraction dépend toujours du HTML Webwidget. Athlete Instructions locales au Studio non synchronisées dans la playlist ; ne pas présumer de leur présence. Les HWPO complexes nécessitent encore une itération.
