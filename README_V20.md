# CFL Control V20 — Mise en page Agenda Admin

- Le retour **← CFL CONTROL** apparaît désormais au-dessus de toutes les actions Admin.
- Les actions Nouvel événement, Modifier un événement, Brouillons et Voir l’agenda public se trouvent dans la barre suivante.
- Le bandeau récapitulatif bleu des vacances scolaires a été supprimé de l’Admin.
- Les boutons **Repères vaudois** et les marquages des vacances / jours fériés dans le calendrier sont conservés.
- Le bandeau de diagnostic des brouillons a été simplifié : total et raccourcis par année.
- Agenda public, CFL TV, BTWB, Supabase et SQL non modifiés.

Déployer en remplaçant les fichiers du dépôt GitHub avec le contenu du ZIP. Aucun SQL nécessaire.
