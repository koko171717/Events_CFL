# V48 — Case Box fermée visible dans la création des événements

La case à cocher « Box fermée » se trouve immédiatement sous les dates de début et de fin dans les formulaires de création et de modification de l’Agenda administrateur. Elle reste désactivée par défaut, sauvegardée dans Supabase via `box_closed` et affichée sur les événements publiés.

Pré-requis: migration `supabase/06_box_fermee.sql` déjà exécutée (sinon à exécuter une fois).
